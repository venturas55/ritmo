# Política de privacidad — borrador para adaptar y publicar

Ritmo guarda hábitos, horarios de recordatorios y marcas de cumplimiento localmente en una base de datos SQLite del dispositivo. Esta versión no pide cuentas ni envía esos datos a un servidor del desarrollador. Las notificaciones son programadas en el propio sistema operativo. La exportación JSON solo se comparte cuando el usuario lo solicita, mediante el cuadro nativo de compartir.

La persona usuaria puede eliminar todos sus registros en Ajustes y puede exportar una copia de sus datos. Si desinstala la aplicación, el sistema puede eliminar el almacenamiento local.

**Antes de publicar:** completar identidad y contacto real del responsable, política de retención, servicios de terceros si se añaden, mecanismos de contacto, legislación aplicable, fecha de vigencia y URL pública accesible. Comprobar que la declaración App Privacy de App Store Connect coincide con el comportamiento efectivo de la compilación.
