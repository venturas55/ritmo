# App Review notes — owner must confirm against submitted build

Ritmo is a Spanish-language, local personal habit tracker. No login, account, demo credentials, backend setup or special hardware is required. All implemented functions are available immediately after launch.

Create: Hoy > + / Añadir nuevo hábito > enter name > choose weekdays > Crear hábito.
Complete: tap a habit in Hoy. Edit/delete: tap its arrow or long-press it.
Calendar: Calendario; past marks can be adjusted from the habit creation date; future marks cannot be set.
Statistics: Progreso shows the last seven days and current streaks.
Reminders: edit a habit > Recordatorio > time in 24-hour format > save. Notifications are optional and local; grant permission only if testing reminders.
Export: Ajustes > Exportar datos opens the native JSON share sheet. No import function exists.
Erase: Ajustes > Eliminar todos mis datos > Eliminar todo. This is local data deletion, not account deletion; there are no accounts. Copies already shared elsewhere remain at their destination.

No in-app purchases, subscriptions, advertising, public posts, chat or social content are implemented in the reviewed source. No purchase restoration or public-content moderation flows exist.
