2. Qué información utiliza RITMO

La aplicación permite crear hábitos, definir días y horarios y registrar su cumplimiento. Estos datos se almacenan en una base de datos SQLite del dispositivo. La versión descrita no exige una cuenta de usuario ni envía el historial de hábitos a un servidor propio del desarrollador.

3. Para qué se utilizan los datos

Se utilizan en el dispositivo para mostrar tus hábitos, calcular estadísticas, consultar tu calendario y configurar los recordatorios que solicites.

4. Notificaciones

Si activas los recordatorios y concedes permiso, RITMO programa notificaciones locales usando las funciones del sistema operativo. Puedes modificar los permisos desde Ajustes de iOS.

5. Compartir y exportar

Cuando eliges exportar tus datos, RITMO genera un archivo JSON y permite compartirlo mediante el panel nativo de iOS. El destino lo eliges tú; desde ese momento, el tratamiento del archivo puede depender del servicio con el que decidas compartirlo.

6. Conservación y eliminación

Los hábitos se conservan en el dispositivo hasta que los eliminas desde la propia aplicación o desaparecen al borrar sus datos. Puedes utilizar la opción «Eliminar todos mis datos» en Ajustes. Una copia exportada previamente deberá eliminarse por separado allí donde la hayas guardado.

7. Servicios de terceros

La aplicación utiliza componentes de Expo y React Native y funciones del sistema operativo. Esta descripción no presupone que todos los servicios de terceros carezcan de telemetría: antes de publicar, se deben revisar los paquetes, permisos y flujos de datos reales de la compilación de distribución y reflejarlos en la información de privacidad de App Store Connect.

8. Seguridad

El almacenamiento local se encuentra dentro del espacio de datos de la aplicación en iOS. Recomendamos mantener el dispositivo y su sistema operativo actualizados y protegidos mediante las medidas de seguridad del dispositivo.

9. Derechos y consultas

Puedes consultar, exportar y eliminar la información desde la aplicación. Para cuestiones relativas a privacidad o derechos que correspondan según la normativa aplicable, contacta con CONTACTO_PENDIENTE.

10. Cambios en esta política

Si cambian las funciones o el tratamiento de datos, se actualizará esta política indicando una nueva fecha de revisión.
